Protocolo
LO QUE PASA
EN <5 SEGUNDOS

Desde que llega el mensaje hasta que Carabineros recibe la alerta con ubicación y número. Todo automático.

01
Valentina IA
Mensaje entrante — análisis instantáneo
Valentina recibe el mensaje y lo analiza con IA en milisegundos. Detecta palabra clave, evalúa contexto, identifica el número de origen y lo mapea al punto de monitoreo correspondiente.
0ms
IA procesa
02
Sistema
Identificación del punto y cuadrante
El sistema identifica: de qué número vino el mensaje → a qué punto pertenece → a qué cuadrante de Carabineros corresponde. Automaticamente arma el mensaje de alerta con todos los datos.
<500ms
Mapeo automático
03
Alerta a Carabineros
WhatsApp directo al cuadrante correspondiente
Valentina envía WhatsApp al número de Carabineros del cuadrante con: ubicación exacta, punto de origen, número que alertó, palabra detectada, hora exacta y nivel de alerta. Todo en un mensaje claro y accionable.
<2s
Alerta enviada
04
Dueño / Supervisor
Notificación simultánea al supervisor
Al mismo tiempo que alerta a Carabineros, Valentina notifica al dueño o supervisor de la sala de monitoreo con los mismos datos. El supervisor sabe qué pasó antes de levantar el teléfono.
<3s
Paralelo
05
Sistema
Grabación del evento
El sistema registra automáticamente: mensaje original, hora, número de origen, punto, cuadrante alertado, tiempo de respuesta. Todo queda guardado en base de datos para auditoría y respaldo legal.
Automático
Auditoría
06
Valentina IA
Respuesta al punto de origen
Valentina responde al número que envió la alerta confirmando que el protocolo fue activado: "✅ Alerta recibida. Carabineros cuadrante [X] notificados. Referencia: #ID-XXXXX". El guardia sabe que el sistema funcionó.
<5s
Confirmación

Tecnología
ARQUITECTURA
DEL SISTEMA

Construido sobre la misma base de Valentina — probada, confiable y escalable. Cada componente cumple una función crítica.

🤖
Claude API
La IA que entiende el contexto. Distingue "robo" literal de figurado. Nunca activa falsas alarmas por error de lectura.
claude-sonnet-4-6
📱
Meta WhatsApp API
Canal oficial de WhatsApp. Los mensajes de alerta llegan sin fallos, sin bloqueos, sin demoras. La misma API que usa Valentina.
Meta Cloud API v18
🚂
Railway Server
Backend Python/FastAPI corriendo 24/7 con uptime garantizado. El mismo servidor de Valentina — ya probado y funcionando.
FastAPI + Python
🗄️
PostgreSQL
Base de datos que registra cada evento, cada alerta, cada mensaje. Historial completo para auditoría legal si se necesita.
PostgreSQL · Railway
🔄
Make.com
Automatizaciones que orquestan el flujo completo: detección → mapeo → alertas → grabación → notificación. Sin intervención humana.
Make.com Webhooks
📊
Dashboard
Panel web donde el supervisor ve todos los eventos en tiempo real, historial de alertas, estadísticas y configuración de puntos.
Web admin panel
